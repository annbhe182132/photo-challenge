# Photo Challenge

Ứng dụng Photo Challenge xây dựng với React, TypeScript, và Tailwind CSS.

## Tech Stack
- **Framework:** React 19 + Vite + TypeScript
- **Styling:** Tailwind CSS v4
- **UI & Animations:** Framer Motion, Lucide Icons, React Icons
- **Routing:** React Router v7

## Hướng dẫn cài đặt và chạy

```bash
# Cài đặt dependencies
npm install

# Khởi chạy môi trường dev
npm run dev

# Build production
npm run build
```
